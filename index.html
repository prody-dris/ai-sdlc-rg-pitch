Slide 03 / The Moat

Why this isn't just another template stack.

Templates are commodity. This is methodology.

Four Differentiators

01

Phase-explicit SDLC

Intent · Solutioning · TRD. Three hard gates with crisp criteria. No consultancy does this cleanly — they collapse it all into "BRD."

02

AI-native execution

Every phase has a Tool + a named Skill + an Owner. AI raises PRs into the skills repo when gaps appear.

03

Three verticals run parallel

Knowledge Management · DevOps · Project Governance check every phase — not bolted on at the end.

04

Stack-aware fan-out

Same methodology. Four distribution tracks with calibrated intensity per stack — covered on slide 19.

Slide 20 / Tool Philosophy

We don't buy tools. We build them.

Five tools serve all ten steps. AI does the work — we only pay for what AI can't do.

The Whole Stack

ToolUsed in stepsWhy this, not SaaSCost
GitHub 1 · 3 · 4 · 5 · 7 · 8 · 9 · 10 + PM Single source of truth — docs, FRs, charters, wireframes, data models, and project management (status, decisions log, SteerCo MoMs, action items, risks). Version-controlled. Push → site rebuilds via GitHub Pages → CloudFront fronts client domains. One repo per project. The project website IS the PM dashboard AND the client artefact. Free · private repos
Claude CLI 1 · 3 · 4 · 5 · 6 · 7 · 8 · 9 · 10 Authors, reviews, maintains every artefact in the repo — including base HTML/CSS wireframes. Renders as a project website. Already licensed
Mermaid 6 · 7 Markdown-native diagrams · workflows + ER. AI-friendly. No drawing tools. Free
Google Stitch 8 (Wireframes) AI-first UI design — prompt → polished mockup → HTML export. No Figma file lock. Lives in GitHub like everything else. Free · Labs
Fireflies.ai 2 (MoM only) Audio capture — the one thing AI can't fake. Transcript drops into the repo; prody-mom takes over. Free · 800 min/mo

The moat is the cost structure — and the unified artefact. Every other consultancy stacks SaaS subscriptions — Notion, Linear, Confluence, Jira, Miro, Figma, Google Workspace. Our entire stack is free or already-licensed. Five tools, ten steps. Docs, FRs, charters, wireframes, data models, workflows, and even project management — status, decisions, action items, SteerCo notes — all live in one project GitHub repo, authored by Claude CLI. Push to main → GitHub Pages rebuilds → CloudFront serves it on the client's domain. The project website is the PM dashboard is the client deliverable. One source of truth. This deck is the proof — built, published, version-controlled, AI-maintained, in under 90 minutes.
