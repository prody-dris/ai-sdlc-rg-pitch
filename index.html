03 / The Moat

Why this isn't just another template stack.

1. Phase-explicit SDLC

Intent · Solutioning · TRD. Three hard gates with crisp criteria. No consultancy does this cleanly — they collapse it all into "BRD."

2. AI-native execution

Every phase has a Tool + a named Skill + an Owner. AI raises PRs into the skills repo when gaps appear.

3. Three verticals run parallel

Knowledge Management, DevOps, Project Governance check every phase — not bolted on at the end.

4. Stack-aware fan-out

Same methodology. Four distribution tracks. Calibrated intensity per stack — covered in slide 19.

18 / The Four Stacks

One methodology. Four distribution tracks.

Stack What it is RG treatment Distribution
mGrant Donor + CSR products Pre-built FR templates per module · fit-gap analysis against existing flows mgrant-stack Frappe plugin
mGrant NuO NGO-facing — sub-grants, FCRA, results framework, PUR Separate FR template set; NGO personas; FCRA + LFA-specific Sol Doc sections mgrant-nuo-stack Frappe plugin
Frappe Services, customizations, mForm (offline app is increment) Generic DocType + workflow scaffolding; mForm adds offline-Flutter delta at Steps 7 + 8 frappe-build-stack plugin
Non-Frappe Greenfield — analytics, custom React/Vue/Python No Frappe assumptions; stack picker at TRD; data dictionary serves chosen DB Methodology pack — Claude/Cursor skills + templates · no plugin

Why mForm sits inside Frappe Stack: it's a project MIS on Frappe; the only differentiator is the offline-first Flutter app. That's a one-layer artefact increment at Steps 7 + 8 — not a new SDLC.

19 / The Real Question

Does RG need to fork per stack?

No. Same methodology. Calibrated intensity per stack. The depth-dial per step is the stack-specific override — not the process itself.

Step mGrant mGrant NuO Frappe Non-Frappe
1 · Kickoff templated templated standard standard
2 · Discovery + MoM fit-gap NGO personas standard heavy
3 · Charter light standard standard heavy
4 · FRs fit-gap config + gaps full full
7 · Data Model fit-gap + extensions NuO overrides full + mForm offline delta full + stack picker
9 · Sol Doc lighter + FCRA + LFA full 16-section full + stack rationale
Typical effort ~5 days ~2 weeks ~3 weeks ~4 weeks

One process. One toolset. One skills repo. The depth per step varies; the methodology doesn't.
